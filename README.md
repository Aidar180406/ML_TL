# Лабораторная работа: Основы Machine Learning

Данный репозиторий содержит выполненные задания по работе с сервисами и инструментами машинного обучения: **Teachable Machine**, **Pocket AutoML** и фреймворками для развертывания моделей (**FastAPI + Streamlit**).

---

## Содержание репозитория

*   **`Hot-Dog.ipynb`** — Задание 1: Классификация хот-догов (Teachable Machine).
*   **`Hockey.ipynb`** — Задание 2: Классификация хоккеистов (Teachable Machine).
*   **`Cars.ipynb`** — Задание 2 (дополнительно): Классификация автомобилей (Teachable Machine).
*   **`Pocket AutoML.ipynb`** — Задание 3: Работа с мобильным приложением Pocket AutoML.
*   **`api.py`** и **`app.py`** — Задание 4: Разработка API (FastAPI) и веб-интерфейса (Streamlit).

---

## Результаты экспериментов

### 1. Хот-доги (Teachable Machine)
*   **Тестовая выборка:** 56 изображений (28 «Hot-dogs» + 28 «Not Hot-dogs»).
*   **Точность:** Hot-dogs — **85.7%**, Not Hot-dogs — **96.4%**. Общая точность — **91.1%**.
*   **Анализ ошибок:** Модель ошибалась на изображениях с необычным ракурсом (вид сверху) и нарезанными продуктами.

### 2. Хоккей (Teachable Machine)
*   **Тестовая выборка:** 29 изображений (3 класса).
*   **Распределение предсказаний:** Salavat Yulaev (16), Guests (8), Judges (5).
*   **Анализ ошибок:** Модель отлично распознает судей (100%) и гостей (87.5%). Ошибки возникают на общих планах, где на льду одновременно находятся игроки разных команд.

### 3. Автомобили (Teachable Machine)
*   **Тестовая выборка:** 41 изображение (3 класса).
*   **Точность (Accuracy):** Foreign — **95.2%**, Russian — **55.6%**, Trucks — **81.8%**. Общая точность — **82.9%**.
*   **Анализ ошибок:** Грузовики распознаются безошибочно. Основные сложности — со старыми российскими авто и нестандартными спортивными моделями.

### 4. Pocket AutoML (Мобильное приложение)
*   **Устройство:** Samsung Galaxy A31.
*   **Ход работы:** 3 класса, 7 тестов, дообучение (179 -> 196 фото).
*   **Точность:** **95%** после дообучения.
*   **Особенности:** Выявлены ограничения On-Device ML (зависания при добавлении >10 фото за раз).

### 5. FastAPI + Streamlit (Разработка)
*   **Архитектура:** Разделение интерфейса (Streamlit) и модели (FastAPI).
*   **Решенные проблемы:** Сериализация `numpy.float32`, кодировка `labels.txt`, совместимость версий Keras (`DepthwiseConv2D`).

---

##  Главный вывод

В ходе работы были освоены облачные и локальные инструменты ML. Наилучший результат показала модель «Хот-доги» (91.1%). Главный урок: **качество модели напрямую зависит от разнообразия обучающей выборки**. Модели отлично работают на крупных планах, но теряются на общих сценах и размытых фото. Использование Pocket AutoML показало, что On-Device ML требует мощного «железа», но дает возможность непрерывного обучения без интернета.
